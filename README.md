# Privacy Policy for Plant ID Bot

This Privacy Policy explains how the Plant ID Discord Bot ("the Bot") handles, processes, and protects your information. By adding the Bot to your Discord server or interacting with it, you agree to the terms outlined below.

## 1. Data We Collect & How We Use It
* **Image Attachments:** When you submit a photo for plant identification, the Bot temporarily processes the image file.
* **Discord Metadata:** The Bot processes standard Discord API data (such as User IDs, Channel IDs, and Guild IDs) solely to execute commands and send identification results back to the correct channel.

## 2. Third-Party Data Sharing
To identify plants, the Bot passes submitted image attachments to the third-party **PlantNet API**. No personal Discord user metadata (like your username or User ID) is shared with PlantNet. We do not sell, rent, or trade your data to any other third parties.

## 3. Data Retention & Storage
We do not use a permanent database. Images and Discord metadata are only stored temporarily in memory or brief server caches to complete the identification request. They are automatically cleared and are not kept permanently.

## 4. User Rights & Deletion
Because we do not permanently store user data, there is no data history to delete. However, if you have questions or concerns about data processing, you can contact the bot host at: waltherade@gmail.com.

## 5. Changes to This Policy
We may update this policy occasionally to reflect changes in functionality. Continued use of the Bot constitutes acceptance of any updates.
